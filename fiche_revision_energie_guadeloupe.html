🔢 Conversions

📐 Les 4 formules indispensables

Rendement : η = Eutile / Eentrée
Énergie d’entrée : Eentrée = Eutile / η
Puissance : P = U × I
Énergie : E = P × t
CO₂ : masse de CO₂ = énergie × facteur d’émission

🔥 Centrale thermique

Combustible → chaleur → turbine → alternateur → électricité
  • Chaudière → produit la chaleur
  • Turbine → énergie thermique → mécanique
  • Alternateur → mécanique → électrique
  • Transformateur → adapte la tension

Rendements : 76 % × 60 % × 92 % × 97 % ≈ 40,7 %.

🌱 Biomasse

Biomasse → chaleur → turbine → alternateur → électricité

En Guadeloupe : bagasse, résidu de canne à sucre.

1 kg de bagasse = 2,2 kWh

1 tonne de canne → 300 kg de bagasse

🌋 Géothermie

Chaleur du sous-sol → turbine → alternateur → électricité

Énergie renouvelable liée aux zones volcaniques. Dans le document : 14,5 MW.

☀️ Photovoltaïque

Soleil → panneau → électricité → onduleur → réseau

L’onduleur transforme le courant continu en courant alternatif.

P = U × I • panneau étudié : 310 W • tension nominale : 31,9 V

☀️ Photovoltaïque : notions à ne pas confondre

NotionUnitéSignification

Nombre de panneaux : N = Pinstallation / Ppanneau

Exemple du sujet : 2360 kW = 2 360 000 W → 2 360 000 / 310 ≈ 7613 panneaux.

📉 Pertes photovoltaïques

À connaître : onduleur 3 % • température 8 % • câbles/connexions 2 % • ombrage 10 % • faible éclairement 5 % • réflectivité 3 %.

🧮 Méthode pour les exercices

  1. Repérer les données.
  2. Repérer ce qui est demandé.
  3. Choisir la formule.
  4. Mettre les unités compatibles.
  5. Calculer et écrire l’unité du résultat.
Exemple : si une source représente 17 % de 1689 GWh :
1689 × 0,17 ≈ 287 GWh.
Puis avec η = 40,7 % : 287 / 0,407 ≈ 706 GWh d’énergie d’entrée.
